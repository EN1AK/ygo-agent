# 首批能力题：原 actor 冻结基线（2026-10-08）

已将三家族四个合成根接入原模型接口。冻结 100M 多卡组模型贪心执行，通过 1 根、失败 3 根；错误分别定位到鳞茎复活表示、疾风被无效后的战斗选择、燎里回收时的手坑响应。没有更新参数或改动正式 native。

## 逐题结果

| 合成根 | 模型实际行为 | 结果与解释 |
| --- | --- | --- |
| 玻纤—鳞茎—枪管龙 | 发动玻纤，Link 枪管龙，发动墓地鳞茎，**守备表示**复活；攻击一次后进入 Main2 | 失败。step 12 选守备概率 99.71%，攻击表示 0.29%。场上另外两只青眼也为守备，枪管龙没有可用于转守备获二连击的攻击表示对象 |
| 疾风可直接攻击 | 越过攻击表示青眼直接攻击 | 成功，对方 1500 LP 降为 0 |
| 疾风被遮蒙者无效 | 仍攻击青眼 | 失败，选择攻击概率 87.82%，己方 1000 LP 降至 -500。题目只要求本战阶存活，可进入 Main2 或结束回合 |
| 燎里回收交闪 | 不响应燎里效果 | 失败，不响应概率 99.83%；交闪回到手牌。固定局面中遮蒙者能阻止回收，幽鬼兔仅破坏燎里不能阻止回收，限制最多消耗一张手坑 |

逐步编号从 0 开始。概率来自完整合法菜单上的冻结策略分布，不是 Q 值，也不是正确率。combo 中鳞茎是玻纤唯一可拉目标，该选择由原适配器自动完成，不能据此声称模型已学会在多个调整中选鳞茎。

这组观察支持具体的教学靶点：combo 已走到关键表示选择，而非完全不会展开；战斗对照显示模型在效果被无效后没有相应调整；响应题显示当前窗口选择不响应。不能从单根推断某张卡的普遍理解能力。

## 验证与边界

- 10 条参考路线和 4 条模型路线，各独立执行两次，共 28 次；包括先攻击再发动枪管龙效果的替代成功解、鳞茎守备复活失败解、战斗与手坑对照。
- 14 对 JSON 轨迹和观测张量内容完全一致；四个 policy 根与对应 reference 根的菜单、观测、当前参数 RNN 哈希相同。
- 每对取一条，经独立 C API 重放 402 条实际核心响应，所有事件、卡片位置、LP、阶段、胜负及判分精确一致。两次执行共 248 个模型接口决策；原适配器自动响应另记。
- 初始/根窗口累计检查 190 行对手私有区域身份，两个身份通道均未发现泄漏；该统计范围不代表对全部实战隐藏信息做了完整审计。
- 保存 28 份实际 actor 张量 `.npz`，逐步校验其摘要与决策记录关联；教师状态、参考动作、真实未来结算均在诊断记录中，未传入模型。
- 13,553 个模型、sidecar、native、数据库、代码表、语义表、Lua 和选定 Python 源文件前后哈希相同。13 项针对性 Python 回归通过。
- 初始场仍由 Debug fixture 布置；玻纤、燎里真实 Link 召唤，疾风无效由真实遮蒙者发动，后续全部真实引擎结算。尚未证明标准牌表起手可达。

RNN 在每条声明的合成 episode 开始清零；当前 checkpoint 对双方各自的每个原接口观测前向推进，即使该步动作由教师选定也推进。根不清零；原适配器的强制动作历史照常写入，未为自动步骤增加推理。这验证了合成 episode 内恢复，不等于完整实战历史恢复。

本次为 CPU、贪心、固定对手条件的开发诊断。三家族四根不是独立留出集；未测采样策略、更多参数模型、24 题目标覆盖、combo 分段深度完成率、事实预测准确率或实战迁移。`training_ready=false`。没有优化器、训练奖励调整或强度收益结论。
