# Structured-lite native build drift incident — 2026-09-20

## Impact

The CPU Structured-lite smoke training did not start. Versioned observation
validation stopped before optimization because the loaded native extension did
not expose `visible_card_ids_`. No incomplete-feature checkpoint was produced.

## Cause

The CPU build directory contained current Structured-lite C++/Python source but
several historical native extensions. Python selected
`ygopro_ygoenv.cpython-310-x86_64-linux-gnu.so`, SHA-256
`8a032099ea03f605235e97698ce5384d2726cd849532216572c309abfadabe2f`,
which predates the required observation contract. The previously reported
validated extension SHA-256 could no longer be found as a file on the server,
so the validated binary had not been preserved as a release artifact.

A rebuild then failed before compiling project source. XMake 2.9.9 consumed a
newer online package recipe that calls `on_prepare_file`, an API unavailable in
that XMake version. Thus an unchanged project checkout was no longer sufficient
to reproduce the earlier binary.

## Corrections

- `cleanba.py` now supports the versioned observation environment and validates
  checkpoint/schema/semantic/code-list/capacity metadata before loading.
- Runtime releases must follow `docs/reproducible-runtime-releases.md` and carry
  an explicit SHA-256 manifest generated by `create_runtime_manifest.py`.
- Git ignores core dumps and model checkpoints; large artifacts are archived
  under local `dist`, not pushed to GitHub.
- A release is accepted only after its own native module passes the real-engine
  schema self-test. Source version and filename alone are insufficient.

## CPU server inventory decision

All recent Structured-lite source files on the CPU server matched the local
repository except a missing bootstrap import in `import_human_replays.py` and
two one-off combo-BC experiment scripts. The bootstrap fix is retained. The
general pilot and synthetic smoke script remain archived outside the main
training route because they were explicitly designed as a one-time policy-only
experiment.

The 70 MB migrated warm-start checkpoint, its metadata/report, and the 4 MB
historical native module were selected for local `dist` archival. The 1.1 GB
`core.1` crash dump and dependency caches were neither downloaded nor committed.
