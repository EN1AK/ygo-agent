# 决策模型直接控制模拟器：完整对局与后训练验证

2026-10-08，独立分支 `experiment/jev-direct-rl`。

完整对局接口已实现并在 H200 验证。模型接收真实引擎观察，选择当前合法动作，动作回写
引擎；可主动选择隔离推演，将分支结果读回，再选择实际动作。训练直接更新同一个模型。
本文将接口、参数更新和棋力分开验收；当前不作棋力提升结论。

## 已核实的完整对局

使用 Laya multilingual 固定基座、OldSchool 40 张主卡镜像、8000 LP、正常起手与抽牌。
双方由模型分别读取自身可见观察后行动；不调用 ReferencePolicy。唯一/强制引擎响应由
原适配器自动处理，另记原始响应，因此核心响应数高于模型动作数。

| full-duel-search-001 | 389 | 1147 | 2530 | 2 | 第 72 回合，座位 0 胜 |

两局的 WIN 帧均为 `05 00 02`，对应座位 0 获胜、对方抽牌失败。结束时双方仍有 LP，
不是有效进攻能力的证据。每局在独立原生进程中重放全部动作，逐步状态指纹、原始响应、
事件、最终字段和种子完全一致。运行分别约 85.19 / 88.12 秒，不含资源准备。
最大实际输入分别为 6195 / 6089 个 Laya token。

## 完整对局奖励到参数更新

`full-duel-rl-001` 使用源码 `29beae184d7950df3279c1e30539a67656f04cac`，先运行 1 局，
再采集同一开局的 2 条完整采样对局，执行 1 次直接 REINFORCE 更新。全部对局均通过自然
终局与独立重放检查。学习率 1e-6、其他轨迹均值 baseline、梯度裁剪 1、推演成本 0.02。

- 编码器存在非零梯度，裁剪前梯度范数 `34.77312088012695`。
- 采样与更新重算 log probability 最大误差 `1.9073486328125e-06`。
- 被追踪的编码器 embedding 参数最大变化 `1.0132789611816406e-06`。
- 训练与保存用时约 424.38 秒，进程退出码 0。
- 输出权重 SHA-256：`a858bb9c5f8965b0e770ce482f5fcea7f7f46a9f9080f516940f1e7105a5f34b`。

这证明完整对局回报能更新模型；尚未做训练前后留出集对战，不能据此声称优于 PPO。

## 模型看到和产生的数据

每条记录包含：

1. 真实引擎的玩家可见局面：区域、动态攻守、无效状态、素材、指示物、装备/对象关系、
   LP、回合、阶段、当前连锁、近期公开事件，以及可见卡片的卡文。
2. 当前合法菜单及原生索引；模型只选择其中一项。对象、素材、连锁响应等后续菜单会再次
   请求模型，不把一次“发动”误当作完整效果结算。
3. 模型自主请求的分支结果：状态变化、新公开事件、新可见卡文、深度及是否真正终局。
4. 选择概率、采样动作、原始响应和随后真实状态；自然终局附加胜负奖励。

因此在线 RL 不要求人工给每一步标注“最佳动作”。模拟器产生交互数据与胜负；训练需要
保留采样时的模型版本、完整实际输入、动作概率、奖励及状态恢复证据。

## Qwen 4B 分支

实现 `--backend openjev-qwen`：固定 Qwen3-4B，原生上下文上限 32768，直接读取选项字母
token 的概率；超过 26 项使用分组条件分布保留所有合法动作。Q/V 投影内 rank-8 LoRA
接受直接 RL 梯度，基座冻结，没有额外 PPO actor。默认保留 100 条近期可见事件，可配置。

这是采用 [OpenJev Qwen 实现](https://github.com/kw2828/OpenJev) 的选项评分思路，
不是同名 27B 项目的权重或校准复现。[Qwen3-4B 模型页](https://huggingface.co/Qwen/Qwen3-4B)
列出了上下文和许可；本实验固定 revision `1cfa9a7208912126459214e8b04321603b3df60c`。
三个基座分片均通过固定 SHA-256 校验，已经在 GPU 上实际加载。首轮
`qwen-full-duel-001` 使用源码 `2cb7a91cf54fac528dbff6279ea2613d91512b2b`：

| 轨迹 | 实际动作 | 回合数 | 座位 0 / 1 最终 LP | 最大 Qwen 输入 token |
| --- | ---: | ---: | --- | ---: |
| 初始完整对局 | 156 | 23 | 2500 / -1950 | 5293 |
| 训练轨迹 0 | 154 | 25 | 5300 / -550 | 5537 |
| 训练轨迹 1 | 262 | 47 | 550 / -700 | 5939 |

三局均由模型控制双方，每局自主调用两次推演，自然终局并通过独立重放。初始局保存了
641 个核心响应、1383 个事件。总用时约 265.80 秒。以上都是同模型自博弈结果，不能
把座位 0 的胜场算作相对基线的模型胜率，也不能直接与 Laya 单局比较棋力。

这轮训练的两条学习方回报均为 +1，学习方没有产生推演成本，其他轨迹均值 baseline
使所有优势归零。梯度及参数变化均为 0，`parameter_update_verified=false`，不算完成
Qwen 参数更新验收。随后增加显式 `--baseline zero`，在开始采样前固定选择普通
REINFORCE 的零 baseline；其方差较高，未按轨迹结果自动切换，也未修改环境奖励。

第二轮 `qwen-full-duel-sky-001` 使用源码
`84757d33a42fe0a1fc365d8a10eddc58d1905984`、种子 8102027、闪刀姬镜像牌表及零 baseline。
学习率 1e-6，每组 2 条轨迹，事件窗口 100，最多 2 次深度 4 的推演；可训练 LoRA 参数
共 2,949,120 个。

## 限制与证据

精确重放推演依赖真实隐藏状态，属于显式开启的 **oracle 诊断**；尚未实现信息集采样，
不能用它报告公平隐藏信息对战胜率。默认关闭推演。输入隐藏私有卡牌身份仍不能消除
oracle 推演对未来结果的影响。未解释事件类型明确列出，更多机制仍需单独审计。
