## Goals / Non-Goals

**Goals:** 在同一证据契约下连接“发生什么”的机制诊断、“选哪个动作”的能力评估及“如何完成目标”的 combo 教学。先交付可执行、可复核的小题库，再分别验证机制理解、决策迁移和实战收益。

**Non-Goals:** 不硬编码永远保留遮蒙者或禁止低攻撞高攻；不奖励发动次数或 combo 长度；不建设完整世界模型或通用任意状态编辑器；不在首批题目中证明全局最优策略。此次只修订规划，不改活动训练、用户 BO3、TRAINING_PLAN 或其他 change；后续教学通过独立入口运行，不自动启用 Q-boost、在线搜索或修改正式模型。

## Decisions

### 1. 首项是来源核验，不是立即训练辅助头

保留冻结 native/hash，隔离 CPU 复现该例并采集连锁前后公开事件；关联引擎消息 link、source CID、actor、原始字节、模型观测和 engine log。检查已有 `_protocol_chain_adapter_fixture` 可覆盖范围：当前测试主要覆盖选择/返回值，不等同于连锁结算来源覆盖。必要时在隔离构建中增加只读追踪与事件 fixture，不覆盖生产模块。

覆盖两链逆序结算、三链、来源离场、无效/禁用、连续新链、回合/对局重置。若确认缺陷，以 link→来源记录表保存当时公开身份，按消息编号取来源；没有可信来源时 unknown，不猜最后发动者。选择窗口来源与结算事件来源分别校验。将事件语义修复独立版本化；新旧观测不能默默混用。

### 2. 事实标签和价值偏好分层

记录 observation/action、对手实际响应、link/source/target、实际支付成本、目标离场、无效状态、召唤/移动/回收等可核验结果，以及证据区间。`CHAIN_SOLVED` 只表示结算事件，不自动标记“效果成功”。未经证明的成本归因、效果成功和未来价值为 unknown。

“交了一张牌却未阻止当前效果”可作为事实；“一定不该交”仍取决于逼迫响应、后续机会与信息。不能把局部少亏牌直接变成终局价值标签。人类录像可以补充策略偏好，但不是唯一标签来源。

### 3. 区分响应条件预测与决策时预测

先预测 P(短期公开结果 | 当前可见历史, 动作, 给定响应)。给定的真实响应属于回顾性教师条件，不能在选择动作时偷看未来。以后如用于决策，必须另建响应分布或合法分支，并传播不确定性。教师可以用引擎私有状态核验事实，但学生输入、检索键及数据切分不能泄漏对手手牌/牌序。

### 4. 保留有限预算探针，扩展家族隔离

既有至多 500 条窗口试点保留为历史诊断数据；只有通过标签、上下文和可见性审计的行才能复用，不为凑题数复制一个根状态。新题目另建版本化清单，保留目标逃逸、无法逃逸、支付成本后获益等有证据反例。

拟合前冻结开发和测试清单。按原始对局/种子组、模板家族、同一 combo 的所有切片与派生变体建立分组约束；共享任一来源的样本作为同组分配，冲突则隔离。另设源/目标/响应卡片组合留出。分别报告数值泛化、机制组合泛化和完整对局迁移，不能把换数值题称为跨机制泛化。评估集不参与模板修订或自适应课程选择；已用于开发的基线题不得重新命名为未见测试题。

比较多数类、卡 ID/静态标签浅层基线、冻结 actor 表示探针、原始公开结构特征探针；actor 参数始终不动。报告逐类 precision/recall、macro-F1、Brier/校准、unknown 覆盖率和按对局聚类的差值区间。若测试只有遮蒙者/零衣，不宣称跨机制泛化。

机制辅助监督的探针门槛保持为：来源 fixture 零错配、无信息泄漏、关键标签有完整证据；留出组合上相对最强简单基线的 macro-F1 差值 95% 聚类区间下界大于 0，且 Brier 不恶化。小样本不足时结论为未通过/不确定。这个门槛用于该类预测监督，不把冻结表示已能预测设为所有示范教学的必要条件；示范路线须独立通过题解、信息边界和数据覆盖审计。

### 5. 统一题目契约，分开三种监督

每题记录版本、能力标签、template/family/parent/duel 标识、来源证据、运行时/卡库/脚本/卡组哈希、种子与动作前缀、当前玩家、根观测和合法菜单摘要、适用条件、对手/随机条件、最大决策数/引擎推进预算、目标谓词、禁止结果/资源约束、判分器版本、参考解证据及 split。标签类型区分：

| 类型 | 可监督内容 | 不允许的推断 |
|---|---|---|
| 条件事实 | 给定动作及明确响应后，成本/移动/效果的已证实结果 | 将已知未来响应输入决策策略 |
| 行动偏好 | 在声明信息、目标和续行预算下，两个已核验分支的比较 | 将未探索动作全部判错，或局部资源变化称为真实 Q |
| 目标达成 | 有界行动序列是否合法并满足目标/约束 | 将一个可行解宣称为唯一或最优解 |

输出区分 success、verified_failure、unknown、invalid_fixture 和 budget_exhausted；报告各自计数及接受率。对于有明确步数限制的题，超出步数可记该任务未完成，但不能据此证明该局面无解。引擎错误、恢复分歧及未知标签不能被静默丢弃或当作模型战略错误。

中文题干和解释用于人工审阅；策略仍消费真实合法观测/动作菜单。目标默认是训练/评估元数据，不偷塞进 actor 输入。仅将与现有策略目标一致的示范用于教学；任意指令目标的条件策略需要另行定义输入与模型契约，不属于本版。

### 6. 模板与实战失误共同出题，引擎负责核验

人工定义能力、适用条件和关键变量；优先从合法对局及可重放前缀产生根状态，参考路线可来自人工、脚本、录像或已验收搜索。所有参考路线须在固定资产的真实引擎上重新执行，不能把自然语言攻略直接视为真值。

每个家族同时设计关键条件改变导致结果/选择变化的对照，以及不改变结论的干扰信息或数值变体。基础战斗先覆盖结果确定的损失与立即获胜；主动牺牲只在收益证据成立时给偏好标签。无法证明“没有后续收益”的普通战斗只标即时结果，不扩大成战略禁令。

不直接修改卡牌攻击力、效果脚本或中途内存来制造真实游戏题；优先通过合法卡牌、效果、起手和行动构造变化。若以后需要人工拼装状态，必须单列为合成机制测试，不能混进实战迁移结果。

对手条件区分无干扰展开、固定合法响应、声明分布的响应采样与真实对局。固定响应下可行不等于对未知对手必胜；隐藏真实手牌分支仅可生成条件事实，不能直接标注公平决策偏好。搜索未找到解也不能标无解。实战失败用于选候选窗口，输掉对局本身不是动作错误标签。

### 7. 长 combo 按目标、依赖和接续深度组织

先验证一条从合法起点到稳定结算后目标的完整路线，再从路线中选择收尾、较长接续和完整起手三个层级；以后加入关键资源变化、顺序限制、合法替代路线和对手打断后的恢复。游戏规则的连锁 link 与跨多个连锁/阶段的 combo 分开记录，不能按连锁数代替展开长度。

以最终目标和资源/次数/召唤限制判分，接受不同合法顺序或替代路线。参考解用于证明可达与提供示范，不做精确字符串匹配。里程碑仅在有引擎证据时用于诊断，首版不按里程碑给额外环境奖励，不默认某个中间场面必然更好。记录首次可验证的失败条件、剩余资源和实际决策长度；无法判定哪一步导致失败时保留 unknown。

恢复中途题时重放完整环境前缀，并针对被评估 checkpoint 从每个玩家的合法历史重算相应 RNN 状态；保存的旧模型 RNN 仅可用于同 checkpoint 复现。训练使用合法历史 burn-in/明确序列边界，不能把中途循环状态置零后称为原局面，也不能把旧 checkpoint 的隐藏状态喂给新模型。目标应在效果结算稳定点检查，阶段/终局边界和对手响应推进都计入题目契约。

### 8. 第一里程碑：目标 24 道可靠题与冻结基线

这是题目契约和判分可用性的开发试点，不是泛化实验。候选审查上限 48 道，目标接受 24 道，三类各 8 道：基础战斗/立即斩杀、交互后果及例外、一个选定卡组的一条已验证 combo 的分段题。每类至少一组成对关键条件变化；combo 需覆盖收尾、接续、完整起手。具体牌例从现有合法资产与可重放证据中选，禁止为了填满配额杜撰答案。全量人工核查这批小题。

实施顺序：先冻结题目字段及候选清单；做每类一对的端到端恢复/判分，再扩至目标数量。首批 combo 的中断恢复是后续扩展项，避免同时解决隐藏信息、搜索和长程教学。参考解重放两次，检查根观测、逐步合法菜单/响应和目标结果一致；同 checkpoint 的模型复现还需匹配历史/RNN。旧 500 窗口只有完成所需输入和动作关联审计的样本才可加入，新采集合格样本不必等待所有旧窗口补齐。

冻结一个兼容运行时的现有 checkpoint，用相同 actor 接口做基线，不改参数。交付题目清单、证据/哈希、参考路线、每题执行轨迹，以及三类分项报告；记录每种拒收原因、事实标签/unknown 覆盖、已验证选择的错误率和各深度 combo 完成率，不合成一个失去含义的总分。现有 actor 没有显式后果预测接口，首批仅核验这些事实并评价其行动；条件事实预测准确率在第 4 节探针实际建立后另报，不从策略 logits 虚构预测分数。

完成标准是所有接受题可复现、答案证据完整、输入边界通过审计、目标判分接受替代解，并用破坏关键前提的例子确认不会误判成功；各题型能通过原模型接口运行。若 48 道候选仍不能覆盖三类及对照，交付缺口报告，里程碑标为未完成；不自动扩大采集预算或直接训练。即使达到 24 道，也不能宣称泛化或统计显著收益。

### 9. 从能力诊断到独立教学实验

首个教学实验优先使用引擎验证的成功接续做短序列示范学习，在冻结 checkpoint 的副本上运行；先验证能否学会开发样本，再在预先留出的家族/组合上检查迁移。示范的单个选择可以用于行为克隆，但不能宣称其他合法动作都是错误。已证明多个首步可接受时，报告有效动作集合的概率质量；偏好训练只使用有证据的成对比较。条件事实的 unknown 标签不进入监督损失。

先使用固定的分层混合：基础、交互、短接续、完整展开，保留已会能力的复习样本。固定课程有效后，再按独立开发题的错误率与学习进展调整采样，设每类上下限，排除无解未证/标签不全题；冻结测试集不驱动采样。所有派生题的组身份不变，不通过重新生成变体跨越划分。

机制后果辅助头作为单独实验，遵守第 4 节探针门槛；示范教学、辅助头、自适应课程和搜索蒸馏不同时引入。搜索目标只能从 `add-mcts-policy-search` 已验收的导出接口消费，并保留搜索模式、预算和不确定性，不把 oracle 隐藏信息变成公平策略答案。

实施训练前冻结实验清单：起点 checkpoint/运行时、训练/留出数据、优化与课程配置、最大更新数、引擎步数、教师生成/搜索开销、墙钟/计算预算、停止条件和最低有意义改进阈值。比较普通 PPO 续训与“教学后 PPO”的匹配实验，增加等计算量普通更新对照以辨别收益是否只是多做了更新；不把教学成本排除在总预算外。初期不改变环境奖励，不将技术超时和题目失败混同。

分别报告记忆开发题、留出题迁移、完整对局强度；实战使用未见种子/卡组组合、双座位、多类对手和无搜索基础策略，给出配对不确定性、吞吐、超时和无效局。探针通过、训练 loss 下降或首批题目全对都不构成实战推广依据。样本量或置信区间不足则明确“不确定”，不自动升级长训练。

### 10. 场景与实战决策的候选生产流程

执行方法见 `docs/capability-exercise-workflow.md`。自然语言先形成目标、起点、适用条件和缺失项；当前仅支持显式指定已实现的三个家族模板。日志导入保存原始文件/决策/模型哈希、菜单和怀疑原因，循环保护、记录的异常或重复观测只触发候选，不直接产生负标签。单方日志不得冒充双方完整历史；通用新场景在没有恢复适配器时拒绝自动套模板。

流程分为候选、真实机制验证、actor/历史审计、冻结评测、教学及实战回归。首版三家族包含四个固定局面、十个执行分支；每分支两次独立 duel 验证，保存合成场到根的前缀和稳定结算结果。采用隔离 C API 桥接，不改生产扩展。其教师状态不属于原 actor 观测；全部保留 `training_ready=false`，0.2 的历史/RNN与原接口部分仍待完成。

新增模板、实战对局及 combo 切片统一携带 lineage，联合连通分组后划分，开发家族连带变体固定为 development。已有题库的划分须冻结；新批次不能单独重算划分后直接拼接。未探索动作、预算耗尽或无法重放的候选继续保持未知/隔离。

## Risks / Trade-offs

- 错误引擎事件成为监督 → 首先核验消息与来源，保留原始数据和 unknown。
- 模型记卡对或根状态 → 对局分组、组合留出及反例，不用测试结果调整标签规则。
- 静态标签过度承诺 → 报告提取规则来源，不扩大 EXACT 含义；是否改表另行版本化。
- 未来响应或私有状态泄漏 → 分离教师/学生字段，决策时不输入真实未来响应。
- 强度收益与运行时修复混杂 → 修复单独验收，两训练臂使用同一修复版。
- 目标只覆盖好看的终场而不提高胜率 → 目标显式标注任务范围，并用独立完整对局验证；不把指定终场自动标为战略最优。
- 同 combo 切片泄漏或 RNN 恢复失真 → 按家族/对局联合分组，模型更新后重算合法历史，拒收恢复不一致题。
- 稀少正例被批量变体掩盖 → 同时报题目数、独立家族数、原始根数、标签覆盖和拒收数；小题库仅验流程。

## Migration Plan

首版已实施三个开发家族的合成机制题及候选工作流，证据见 `reports/capability-exercises-20261008.md`；这不完成第 0 节整体里程碑。下一步优先接通原 actor 的根观测、动作及合法历史/RNN恢复，再做冻结基线；所用旧样本须完成第 2 节相应审计。之后扩充独立家族、执行探针或示范实验门槛，再进入单独配置的教学与实战对照。

新增题库/报告/训练输出使用独立目录和版本化清单，不覆盖旧 500 窗口或模型。诊断、评估命令不启动优化器；教学命令输出独立 checkpoint，不替换正式评估默认值。需要源代码变更时按 AGENTS 同步，明确未同步端；回滚通过选回原模型和原运行时完成。任何恢复、标签或信息边界门槛失败，只保留诊断证据，不向训练推广。
