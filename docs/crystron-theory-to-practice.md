# 水晶机巧：从理论到实战的监督课程

本轮目标来自用户对实战 FTK 示范过于复杂的反馈：整理并验证单卡基础展开，再加入多卡衍生、抗干扰、后攻处理和实战监督。仅复现四条 FTK 不满足本轮目标；暂不启动 PPO。旧实验、模型和留出集保持不变，已经看过的旧留出样本不能重新宣称未暴露测试集。

## 完成条件

1. 全量盘点已经下载的 975 条录像，取消 60 张牌和 FTK 过滤。补充缺失引擎审计，区分完整结局、合法前缀、损坏、未知。不能把录像中断当作输，也不能只因合法就认定战略正确。
2. 建立可复用的纯资源验证流程。单卡课程必须从一个启动资源、空场空墓出发，保留真实牌组可检索资源，记录卡库、脚本、规则、随机性、额外卡组和路线来源。需要弃牌或第二启动的路线明确标为一加代价或多卡；不冒充单卡。合成单手牌资源证明与正常五手牌适用性分开评估。
3. 按资源转换与功能终点整理单卡模块，再构造明确增加资源的多卡衍生。目标可为铺场、资源获取、建立可用阻抗，不强求 FTK。稳定终点由真实引擎状态验收，存在卡名不等于效果仍可用；功能阻抗需要真实挑战证明。
4. 将抗干扰、后攻解场、战斗和不能斩杀时的后续资源纳入课程。局部局面可作局部示范，但必须保留完整可重建历史与监督范围。不能把对方被动配合下的成功扩展成任意对手都成功。
5. 实现可运行的监督数据准入、家族去重与划分、分阶段采样、完整 RNN 历史和本方决策损失。原始隐藏牌只供引擎重建，不能作为学生输入。失败预算不产生负标签。
6. 在 H200 执行并审核隔离监督试训练，报告基础题、多卡题、后攻题与独立实战条件的自主执行表现，对照训练前模型；下一步预测准确率只能作为辅助指标。保存配置、日志、模型哈希、真实重放和可浏览课程，不以脚本存在替代训练完成。
7. 按项目约定同步本地、GitHub、home、H200 源码，保护用户未提交修改与现有正式运行时。

## 当前入口

`scripts/studies/crystron_curriculum/catalog.py --source <旧研究目录> --output <新清单目录>` 为所有下载录像建立证据清单，尚不自动准入训练。

`collect_single.py --source <旧研究目录> --output <独立新目录> --sha <完整录像哈希> --starter <卡号> --runtime <隔离运行时>` 使用录像决策作为候选向导，在单手牌反事实状态下逐步匹配实际合法动作，遇到分歧保留证据并停止。独立核心审核新的状态和响应，不能拿原录像审核替代。此阶段输出发现材料，未自动赋予可训练或战略最优标签。

进度与冻结协议写入 `training-runs/crystron-curriculum-20261027` 对应交付目录；证据不足时保持目标未完成。
