## Navigation policy revision (user instruction, 2026-10-28)

Future teaching and model execution use the existing filtered policy menu.
Human undo/select-back navigation must not become a teaching target or recurrent
history artifact. Preserve strategic declines (chain/effect activation), valid
selection finish and any correction that the native filter requires to keep a
legal continuation. This changes the earlier full-menu research contract.

Preserve running full-menu experiments as historical evidence. Do not promote
their results as validation of the filtered route. Reconstruct menus, action
indices, observations, histories and roots through the actual filtered adapter;
deleting a training label alone leaves navigation in the recurrent inputs.
Require equal engine responses/events/endpoints for an exact projection. Human
routes that need undo removal require a separately certified equivalent route;
quarantine them with an explicit denominator until that proof exists. Do not
blindly remove every Cancel action or call a changed selection equivalent.

`project_filtered_teaching.py` implements the conservative exact projection and
produces preparation artifacts, not an automatically admitted curriculum.
It never queries a model or uses independent exam scores. A new frozen protocol
and filtered-runtime qualification must precede new teaching/PPO experiments.

The old unconditional selection-Cancel filter was overbroad: S:P Little Knight
uses a cancelable field-first target prompt to reach graveyard targets. Cancel
is filtered only for an uncommitted summon/set material chooser opened from the
idle menu; effect-script branches remain available. Source provenance records
this adapter revision separately from teaching gains. Normalization may erase
only observed loops returning to identical full state, prompt/menu and committed
event prefix. The resulting route must be independently replayed; changed UI
responses alone are not a failure, while changed game events/endpoints are.

Navigation can also change a temporary pending XYZ extra-deck slot. A separate
positive-witness class may rebind only unique extra-card aliases, with XYZ
material destinations linked to the following actual summon. It must preserve
the board, ordered main deck/hand and exact extra inventory, all semantic game
events, and revalidate the original local goal plus independent core replay.
It does not claim identical extra order, hidden internal state or future RNG
realizations. Unresolved or duplicate physical targets remain byte-exact. Audit
automatic core unselect responses as well as model-visible buttons; approved
human teaching must contain neither residual undo nor observed navigation loops.

Independent audit runs in a fresh CPU worker, separate from the CUDA/model
process. Duplicate semantic chain candidates are tested by forking at the
pending core prompt in that single-threaded worker. Every branch must replay
the full remaining trace to the same events and endpoint, within eight complete
variants and sixty seconds; any divergent or unverified branch rejects the
certificate. No arbitrary duplicate index is chosen or called equivalent.

## End state and evidence

1. Freeze environment, policy, opponents, curriculum, independent evaluation,
   budgets and promotion criteria before each experiment. Refuse incompatible
   inputs; preserve full histories, original menus and hidden-information rules.
2. Collect autonomous failures from the current policy. Distinguish invalid
   runtime, incomplete observation, repeated reversible selections, strategic
   failure and unknown/budget exhaustion. A difference from a demonstration is
   a candidate, never automatically a wrong-action label.
3. Restore actual failed prefixes; search useful continuations. Only complete
   goal-reaching routes reproduced by the adapter and independently replayed
   through the raw core become teaching data. Unknowns remain unknown.
4. Compare continuing the original curriculum with adding admitted repairs,
   from the same parent and with equal optimizer-update budgets. Prefix actions
   reconstruct the current model's recurrent history and receive no repair CE.
5. Repeat collection using the updated policy, rather than recycling only the
   initial model's errors. Append typed findings, corrections, run records and
   lessons with evidence hashes. Process completion and scientific improvement
   are separate claims.
6. Validate autonomous transfer on newly frozen player/deck/match components,
   full duels against compatible frozen opponents, both seats and paired seeds.
   Previously inspected holdouts are regression data. Do not select checkpoints
   on the independent exam. Report invalids, uncertainty and search/teaching
   costs in addition to win rate.
7. Run the compatible formal PPO continuation with ordinary-PPO control and
   verified full-history retention, then repeat skills/transfer/full-duel exams.
   Local-course success cannot promote a production default.

restart a process because an observation timed out.

## Search information boundary

Exact historical replay is an offline oracle used to certify local teaching
witnesses. It does not demonstrate fair-play online search or globally optimal
actions. Core RNG is replayed for fidelity; an eventual online branch backend
must separately replace hidden states with legal particles and resample future
randomness. Search-tree visit counts and policy logits are not ground-truth Q.
