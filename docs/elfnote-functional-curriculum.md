# 功能干扰题的可重复教学流程

本入口针对已有合法elfnote完整起手，按配置生成题、重验当前模型、搜索并验收题解，再执行匹配教学与独立审核。它不把任意自然语言或“这步看起来不合理”直接转成负标签。

配置为`assets/exercises/teaching-v1/elfnote-functional-teaching.json`。第一步固定当前父模型、原生引擎、完整历史来源及全部拟合/评价条件，然后执行`scripts/study_elfnote_functional_teaching.py --stage collect`。自动变体只交换注册内合法资源、改变手牌顺序/随机种子，或延后到下一个合法干扰窗口；新双启动仍沿已有明确恢复适配器生成。不可重建的实际场景先用既有候选导入工作流登记缺失项。

采集保留每次搜索尝试。成功必须有真实效果证据、双次actor/逐张量重放、独立核心审核，以及取消响应后失败的反例；手坑自身必须实际结算且未被无效。搜索和新监督仅允许公开响应后、教师挑战前的本座位决策。未找到或未发生预声明响应的题保留未知/未观察，不罚动作、不凑训练配额。

通过收录门槛后，单独执行`--stage train`。旧课程、独立成功路线保护和新纠错权重分别声明，完整合法历史用于当前模型记忆重建；只监督经当前父模型重验的语义分歧。新评价条件不得进入采集、损失、中途检查或选点。训练结束调用`scripts/verify_elfnote_functional_teaching.py`独立核对来源、完整引擎证据、每次目标和训练边界。

一键执行入口`scripts/run_elfnote_functional_teaching.sh`仍显式要求根目录、不可变源码快照和新输出目录，默认不修改正式模型。脚本分别保存采集、教学和最终审核退出状态。若数值、重放或门槛失败，原失败记录保留；后续修复必须有独立版本和重新绑定的协议。

结果分别报告：已教起手、资源变体、干扰时点、其他组合、恢复根、原能力、搜索成本和实战结果。未形成候选终场时，不能根据响应模式0分断言模型不会使用阻抗。题目通过只授予下一阶段研究资格；正式PPO还需要匹配原生运行时、短GPU验证以及独立完整对局评测。

若完整历史上的关键点已拟合、自主轨迹却提前分歧，先保存并比较首次菜单/观测一致处的不同选择。`elfnote-recovery-context.json`提供后续对照：共同增加实际成功的旧纠错全历史复习，以及新路线非纠错上下文KL，再比较单点与完整公开恢复段CE。不能保护已经证实错误的父分布；每条历史的监督索引独立存档，教师结束、挑战及响应仍不作为CE。相同源码入口通过可选`--plan`加载另一个冻结配置；旧评估条件随实验使用转为已暴露数据。
